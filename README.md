# underwater-equipment-monitor
Python-based underwater equipment monitoring and fault alert simulator.
Underwater Equipment Monitor

Project Description

A Python-based underwater equipment monitoring and fault alert simulator that monitors temperature, pressure, and battery levels.

Features

- Simulates temperature, pressure, and battery readings.
- Detects high temperature.
- Detects high pressure.
- Alerts when battery levels are low.
- Displays equipment status.

Technologies Used

- Python
- Random module
- Time module

How to Run

1. Install Python.
2. Run "main.py".
3. Observe the simulated sensor readings and fault alerts.

Note

This project uses simulated sensor data and demonstrates the basic concept of underwater equipment monitoring.
